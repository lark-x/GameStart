# ADR-0001：模块化单体与独立 Worker

- 状态：已接受
- 日期：2026-08-12

## 决策

系统保持 TypeScript monorepo 中的模块化单体 API，并使用独立 Worker 执行调度、队列、图片和发布等异步任务。只有出现可量化的独立扩缩容、故障隔离或团队所有权需求时，才评估拆分服务。

## 原因与影响

当前业务边界仍在快速演进，共享领域规则、Contract 和事务一致性比独立部署更重要。模块边界通过 Domain、Contracts、Ports、Use Case 和 Adapter 表达；不能用“仍是单体”作为跨层调用或堆叠巨型文件的理由。
