# ADR-0006：V2 本地创作者驱动互动游戏平台

- 状态：已接受
- 日期：2026-08-12
- 替代范围：仅适用于明确标记为 V2 replacement 的后续任务；当前 V1 维护任务仍遵守 ADR-0001 至 ADR-0005。

## 决策

Living Network V2 将从当前角色生活模拟系统，替换为本地优先的创作者驱动 AI 互动游戏脚本生成与游玩平台。V2 仍保持 TypeScript monorepo、模块化单体 API、独立 Worker 和 Vue Web，但允许在替换任务中采用以下目标架构：

- API 运行时采用 Fastify。
- 业务事实来源从 PostgreSQL 替换为 SQLite + FTS5。
- Redis 继续只承担 BullMQ 队列及可重建运行数据。
- Qdrant 作为独立向量检索库，只保存可从 SQLite 事实重建的索引。
- `packages/domain` 作为核心领域包，表达故事世界、角色、地理、时间、事实、叙事图、类型化世界状态、候选审核、发布和存档不变量。
- AI、ComfyUI、向量检索和社交自动生成都是不可信适配器，其输出进入候选、草稿或临时会话；除明确允许的临时互动外，不得直接写入 canon、发布内容或玩家存档。

当前 V1 系统代码可作为迁移参考和可复用资产来源，但 V2 不迁移旧数据，不兼容旧 API，不把旧 Repository Bag 或旧状态模型作为目标架构。

## 原因

V2 产品目标已经从“长期运行的 AI 角色社交模拟”转向“创作者生成、审核、发布并游玩互动脚本”。核心复杂度在 canon 世界模型、可审核生成、发布版本和玩家存档，而不是旧系统中的 PostgreSQL 多仓储模型和社交模拟链路。

SQLite + FTS5 更适合本地 Web 应用的单用户事实存储，降低部署和任务分支复杂度。Qdrant 单独承担向量索引，可以避免把向量检索耦合进事实库。Fastify 用于替换当前较大的原生 `node:http` 路由层，但只能在 V2 replacement 分支中使用。

## 影响

- 后续 V2 任务必须先读取 `docs/v2/common-baseline.md`，再读取自己的任务文档。
- V2 分支可以删除或替换 V1 代码，但必须保留可复用资产中明确列出的协议、适配器、测试替身、UI 原语和工程纪律。
- 当前 V1 修复、热补丁或小功能不得引用本 ADR 作为引入 Fastify、SQLite、Qdrant 或破坏旧 API 的理由。
- V2 实施前应先创建归档分支保存当前 V1 状态；归档分支创建由仓库维护者执行，不由并行任务分支各自处理。
